# Безопасность ZV67

## Модель угроз

ZV67 — локальное приложение на одном Mac. Оно не должно быть доступно из локальной сети или интернета. Административная панель имеет отдельную аутентификацию; клиентский API защищается локальным API key.

## Секреты

- Пароль администратора хранится как `scrypt`-хеш в SQLite.
- Мастер-ключ шифрования создаётся один раз. В интерактивном режиме по умолчанию используется macOS Keychain (service `zv67-master-key`); LaunchAgent запускается с файловым хранилищем `0600`, чтобы не зависеть от GUI-подсказок Keychain.
- Cookies и история диалогов шифруются Fernet (AES-128-CBC + HMAC) с версионированным префиксом.
- API keys клиентов хранятся только как SHA-256 хеш.
- Значения credentials не возвращаются Management API и не пишутся в журналы.

Файловое хранилище ключа создаёт файл с правами `0600`; каталог данных — `0700`.

## Доступ

- FastAPI слушает `127.0.0.1` по умолчанию.
- Панель использует HttpOnly cookie `zv67_admin`, SameSite=Strict, path=`/admin`.
- CSRF-токен обязателен для POST/PUT/PATCH/DELETE.
- Запросы с чужим Origin отклоняются.
- После пяти неудачных попыток вход блокируется на пять минут.
- Все изменяющие действия попадают в административный журнал.

## Данные

Журнал запросов хранит метаданные: время, модель, аккаунт, статус, HTTP-код, задержку и код ошибки. Промпты, ответы и cookies в него не попадают.

Удаление аккаунта удаляет связанные credentials, сессии, ходы диалогов и tool calls через внешние ключи SQLite.

## Google AI Mode

Реальный backend запускает отдельный headless Chrome на каждый аккаунт через CDP. Используется временный профиль в системном каталоге; после закрытия сессии процесс завершается, профиль удаляется.

Cookies расшифровываются только в памяти процесса и передаются в изолированный профиль браузера. Они не пишутся в журналы, не попадают в Git и не отображаются в Management API. Содержимое ответов AI Mode сохраняется в зашифрованной истории сессии.

Трафик направляется в Google. Использование неофициального протокола нарушает условия Google и может привести к блокировке аккаунта.

## Ограничения

Локальный API key не защищает от другого процесса того же пользователя macOS. Это ожидаемая граница локального приложения.

Защита панели не заменяет защиту операционной системы и физического доступа к машине.

## Перед публикацией

1. Проверить `git status`.
2. Выполнить поиск секретов по репозиторию.
3. Убедиться, что нет `.env`, cookies, токенов, браузерных профилей и баз данных.
4. Проверить, что скриншоты не содержат приватных данных.
5. Проверить приватность GitHub-репозитория через API после создания.

## Инцидент

При подозрении на утечку:

1. Остановить сервис.
2. Заменить мастер-ключ и перешифровать данные либо удалить затронутые credentials.
3. Сменить пароль администратора и клиентские API keys.
4. Проверить административный журнал и локальные логи.
5. Отозвать доступы у внешних сервисов, если они использовались.
